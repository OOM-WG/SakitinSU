## 项目介绍

> 此仓库为 [**ShiroSU 系列**](https://shirosu.my.id/) 的 root 相关主线，不包含其他项目内容

- [**SSU NT**](https://newtech.shirosu.my.id/) (又称 _SSU ROOT_)
  是基于 `ramdisk` 注入实现的纯用户态 root 实现，采用 **WebUI** 实现 root 管理

  目前支持 Android **10+** 设备，可通过 WebUI 刷入与管理

- [**SSU Compat**](https://compat.shirosu.my.id/) (又称 _SSU 管理器_)
  是兼容多种 root 实现的 root 管理器，可以管理模块与权能
